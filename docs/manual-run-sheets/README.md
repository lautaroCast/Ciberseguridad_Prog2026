Transcripción de las dos hojas de cronometraje del proceso manual de referencia
(condición de control del diseño cuasi-experimental). El protocolo completo está en el
Anexo K del informe final y los mismos valores se reportan en su Tabla 10.

Estos archivos son una **transcripción** de las hojas registradas a mano durante cada

del resto de las mediciones del trabajo, los tiempos del brazo manual provienen de un
cronómetro operado por cada autor y no de marcas temporales del sistema.

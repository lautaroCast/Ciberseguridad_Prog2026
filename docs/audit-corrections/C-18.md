ejecución, informe PDF generado, informe HTML generado, respuesta de la
API) requieren un navegador interactivo. **Confirmado dos veces, en dos

### Decisión pendiente del usuario

No se puede tomar esta decisión de forma unilateral porque las tres
opciones tienen costos distintos para el usuario:

1. **El usuario toma las 4 capturas a mano** (navegando a `localhost:5678`
   para n8n con el workflow importado y corriendo, descargando un reporte
   PDF/HTML generado por cualquiera de las campañas ya ejecutadas, y una
   captura de una respuesta de `GET /scans/{id}/findings` en el
   navegador o en un cliente HTTP). Es la opción más simple si el usuario
   tiene el stack corriendo localmente con acceso a un navegador normal.
2. **Se reintenta Claude in Chrome en una sesión futura** en la que la
   extensión sí esté conectada — sin garantía de cuándo eso ocurra.
3. **Se documenta la ausencia como limitación aceptada** para esta ronda,
   dejando `C-18.md` con los tres diagramas resueltos y las capturas como
   pendiente explícito, no oculto — mejor que lo que había (cero de
   ambos), pero no resuelve el hallazgo por completo.
